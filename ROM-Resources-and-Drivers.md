# ROM Resources & Built-in Drivers

## 1. Overview of the ROM Resource Fork

In the original 1984 Macintosh (64 KB ROM), drivers and system components were linked as static machine code routines with hardcoded entry tables. Beginning with the **Macintosh Plus (128 KB ROM)** and continuing in the **Macintosh SE (256 KB ROM)**, Apple restructured the upper half of the ROM as a formal **Resource Fork** (`res_map.s`).

By formatting the ROM as an immutable resource file, the operating system can load drivers, packages, fonts, window definitions, and menu bars using standard Resource Manager traps (`_GetResource`, `_ReleaseResource`), maintaining a unified architecture across ROM and disk files.

## 2. ROM Resource Map Architecture

The layout of the ROM resource fork is generated by the Rez compiler (`rezc.py`):

```
+---------------------------------------------------------------+
| Resource 1 Data ('DRVR' 4: .Sony Floppy Driver)               |
+---------------------------------------------------------------+
| Resource 2 Data ('DRVR' 3: .Sound Audio Driver)               |
+---------------------------------------------------------------+
| ...                                                           |
+---------------------------------------------------------------+
| Resource N Data ('FONT' 0: Chicago 12 pt System Font)         |
+---------------------------------------------------------------+
| ROM Resource Map Header (Offset to Types, Names, References)  |
+---------------------------------------------------------------+
| Type List: Array of 4-character resource types                |
| ('DRVR', 'PACK', 'WDEF', 'CDEF', 'MDEF', 'MBDF', 'FONT', etc.)|
+---------------------------------------------------------------+
| Reference List: ID, Name Offset, Resource Attributes, Data Off|
+---------------------------------------------------------------+
| Name List: Pascal strings for named resources                 |
+---------------------------------------------------------------+
```

When the Resource Manager initializes, it mounts the ROM resource map at the base of the resource search chain. System global `TopMapHndl` (`$0A50`) points to the topmost open resource file (the active document); if a resource is not found in the application or `System` file, lookup falls through to the ROM.

## 3. Built-in ROM Drivers

### 3.1 The `.Sony` Floppy Driver (`res_drvr_sony.s` / `res_drvr_sony_fdhd.s`)
- **Driver Reference Number**: `-5` (Unit 4).
- **Supported Drives**:
  - Drive 1: Internal 3.5" drive.
  - Drive 2: External 3.5" drive.
- **Mac Plus & SE**:
  - Interfaces with the **IWM** chip.
  - Implements **GCR 400K/800K** disk reading, writing, formatting, and disk motor speed control (PWM table interpolation).
- **Mac SE FDHD Variant (`res_drvr_sony_fdhd.s`)**:
  - Interfaces with the **SWIM** chip.
  - Adds full **1.44 MB MFM** track formatting, sector interleave calculation, and high-density disk sensor detection.

### 3.2 The `.Sound` Driver (`res_drvr_sound.s`)
- **Driver Reference Number**: `-1` (Unit 0).
- Provides square-wave, wave-table, and free-form audio synthesis.
- Fetches sample bytes from the 370-byte sound buffer during horizontal blanking intervals.

### 3.3 The AppleTalk Stack (`.MPP`, `.ATP`, `.XPP`)
- **`.MPP` (Macintosh Packet Protocol - RefNum `-9`)**:
  - Implements the physical and data-link layers of LocalTalk (LLAP - LocalTalk Link Access Protocol).
  - Handles node address discovery, dynamic addressing (1 to 254), packet framing, and hardware CRC verification via the Zilog 8530 SCC.
- **`.ATP` (AppleTalk Transaction Protocol - RefNum `-10`)**:
  - Implements reliable, transaction-oriented request/response transport.
  - Handles packet acknowledgments, retries, and multi-packet reassembly.
- **`.XPP` (Extended Protocol Package - SE ROM)**:
  - Implements AppleTalk Filing Protocol (AFP) client glue and Printer Access Protocol (PAP) for laser printing directly across network cables.

## 4. Standard ROM Packages (`PACK`)

Complex operating system components that are not required continuously are packaged as dynamically loaded **Packages** (`_Pack0` through `_Pack7`):

### 4.1 Pack 4: SANE Floating-Point Engine (`res_pack_4.s`)
- Implements the **Standard Apple Numeric Environment (SANE)** conforming to the IEEE 754-1985 standard.
- Supports 32-bit Single, 64-bit Double, and **80-bit Extended Precision** floating point numbers entirely in 68000 assembly!
- Performs arithmetic operations, square roots, rounding, and format conversions without needing a math coprocessor (FPU).

### 4.2 Pack 5: Transcendental Math Package (`res_pack_5.s`)
- Computes trigonometric functions: $\sin(x), \cos(x), \tan(x), \arctan(x)$.
- Computes exponential and logarithmic functions: $\ln(x), \log_2(x), e^x, 2^x, y^x$.
- Financial compound interest calculations.

### 4.3 Pack 7: Binary-Decimal Conversion (`res_pack_7.s`)
- Fast conversion between 16/32-bit binary integers and ASCII decimal strings (`NumToString`, `StringToNum`).

## 5. Standard Definition Procedures

Definition procedures dictate how standard user interface widgets are drawn and interacted with:

### 5.1 Window Definition: `WDEF` 0 & 1 (`res_wdef*.s`)
- `WDEF 0`: Standard document window (title bar, close box, zoom box, size box, content region).
- `WDEF 1`: Alert box / modal dialog window with rounded corners.

### 5.2 Control Definition: `CDEF` 0 & 1 (`res_cdef*.s`)
- `CDEF 0`: Standard pushbuttons, checkboxes, and radio buttons.
- `CDEF 1`: Scroll bars (up/down arrows, gray page track, draggable thumb indicator).

### 5.3 Menu & Menu Bar Definitions: `MDEF` 0 & `MBDF` 0 (`res_mdef.s`, `res_mbdf.s`)
- `MDEF 0`: Draws drop-down menu items, checkmarks, keyboard command shortcuts ($\mathscr{H}$), and submenus.
- `MBDF 0` (Mac SE): Draws the 20-pixel high desktop menu bar, displays the Apple logo icon, highlights inverted menu titles, and draws the drop shadow.

## 6. ROM Fonts & Cursors

- **Chicago 12 pt (`'FONT'` 0)**: The iconic system font designed by Susan Kare, stored directly in ROM (`res_font_chicago.s`). Used for menu bars, window titles, and alert messages.
- **Geneva 9 & 12 pt (`'FONT'` 3)**: Clean proportional sans-serif font included in Mac SE ROM (`res_font_geneva.s`).
- **Monaco 9 & 12 pt (`'FONT'` 4)**: Fixed-width monospace font included in Mac SE ROM (`res_font_monaco.s`).
- **Standard Cursors (`'CURS'`)**: Arrow pointer (`arrow`), I-beam text editing cursor, Crosshair, Plus cursor, and Watch cursor.
